# 지도 핀 혼잡도 수정 검증 (2026-11-02)

기존 지도 탐색 기능의 보완 작업입니다. 추가 키·사용자 설정은 필요하지 않습니다.

- 카카오 공식 MarkerClusterer로 가까운 핀을 묶습니다. 레벨 5 이상, 80px 격자, 최소 2개이며 숫자는 묶인 상권 개수입니다.
- 숫자 원 클릭 시 확대하고 상세 확대 시 개별 핀을 표시합니다. 이름 라벨은 선택한 상권만 표시합니다.
- 기존 선택·목록·관심 저장 계약과 통계 계산은 변경하지 않습니다.
- SDK에 services와 clusterer를 함께 로드하고 지도 정리 시 묶음도 제거합니다.

검증 결과:

- `npm run build`: 통과 (기존 500kB 번들 크기 경고).
- `npm test`: 9개 파일, 33개 테스트 통과.
- `Invoke-RestMethod http://127.0.0.1:8000/health`: ok.
- `/api/v1/industries`: 커피-음료 정상 조회. 구버전 서버에서는 404였으며 현재 코드로 재시작 후 해결.
- `/api/v1/trade-areas`: 1,650곳 정상 조회.
- PC 브라우저: 전체 지도 숫자 묶음, 묶음 클릭 확대 확인.
- 360px 모바일: 지도·필터 표시와 숫자 묶음 확인.

실행: 프로젝트 가상환경 Python으로 `-m uvicorn app.main:app --host 127.0.0.1 --port 8000`을 backend 폴더에서 백그라운드 실행했습니다. 재부팅 후 자동 시작 설정은 포함하지 않습니다.

공식 참고: https://apis.map.kakao.com/web/sample/basicClusterer/
