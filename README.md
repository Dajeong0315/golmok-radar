# 골목 레이더 (golmok-radar)

첫 매장 창업을 준비하는 사람이 지도에서 관심 상권을 모으고 최대 네 곳을 같은 기준분기로 비교하며,
모든 숫자의 원천값·출처·계산식을 직접 확인한 뒤 현장에서 확인할 질문을 정리하는 반응형 웹입니다.

- 분석 범위: 서울 성동구·광진구, 카페
- 기술 스택: React + TypeScript / FastAPI / Supabase(PostgreSQL) / 카카오맵
- 결정사항: `docs/프로젝트_결정사항_v2.md`
- 확장 아이디어: `docs/확장메모.md`
- 원천 데이터 기록: `docs/data_sources.md`

> 실행 방법과 기능 설명은 개발이 진행되면서 채웁니다.
