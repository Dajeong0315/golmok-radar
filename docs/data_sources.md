## 8. V2 리뷰 데이터 계약

카카오 장소 검색과 주변 동종 가게 구성 로직은 구현돼 있지만, 정식 리뷰 데이터 제공자의 답변과 이용 권한이 확인될 때까지 공개 화면에서는 실행하지 않습니다. 리뷰 화면은 ‘준비 중’ 상태와 향후 제공 범위만 안내하며 리뷰 입력·수집·분석 결과를 노출하지 않습니다. 카카오나 네이버의 리뷰 화면 또는 비공개 엔드포인트를 수집하지 않습니다. 리뷰 비교 API는 정식 제공자와 분석·재사용·표시 권리가 계약으로 확인되기 전까지 fixture 기반 검증 용도로만 유지합니다.

- 비교 주제: 메뉴·맛, 가격, 응대, 대기, 청결, 공간·분위기
- 분석 방법: 공개된 키워드 포함 여부와 단순 긍·부정 어휘 수 비교
- 표본 기준: 내 가게와 주변 비교군 각각 5개 미만이면 집계만 표시하고 실행 아이디어는 숨김
- 내부 fixture 계약: `group`은 `own` 또는 `nearby`, `review`는 비식별 테스트 문구이며 각 그룹 최대 500건
- 근거: 주제별 리뷰 순번과 최대 80자의 비식별 문구를 최대 3건 반환하고 인사이트에서 해당 주제로 연결
- 한계: 문맥·반어·복합 감정을 완전히 이해하지 못하며 대표성이나 인과관계를 보장하지 않음

NAVER Place나 카카오 장소의 리뷰를 비공개 API 또는 화면 크롤링으로 수집하지 않습니다. 정식 제공자 API는 저자 표시·원문 링크·저장 제한과 이용약관을 충족하는 adapter가 준비된 뒤 연결합니다. 2026년 11월 1일 다이닝코드와 Tripadvisor Terra 문의는 접수됐고, 식신 MetaDex 문의는 HTTP 500으로 접수되지 않았습니다. 상세 현황은 `docs/review_provider_outreach.md`에 기록합니다.
