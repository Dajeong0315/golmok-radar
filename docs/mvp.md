# 골목 레이더 MVP

> 범위 구분: 아래는 최초 MVP 기록입니다. 소개형 홈·마이페이지·비로그인 60분 보관·로그인 시 기록 이관·재시험은 plan.md Phase 23~28에서 완료했습니다. 전체 업종 확장은 Phase 29~33에서 완료했습니다. 최초 MVP의 카페 한정·영구 브라우저 저장·계정 기능 제외 정책은 확장 범위에서 대체했습니다.

> 이 문서는 Phase 0~8에서 구현한 1차 상권 판단 엔진의 완료 범위를 보존합니다. 창업 성향 진단·조건 기반 후보 탐색·임대·자금·리뷰 분석·매물 검증 워크시트를 포함한 확장 컨셉은 `docs/product_v2_pipeline.md`를 기준으로 합니다. 워크시트는 V2 별도 기능이며 이 MVP의 상권 비교 API·계산 계약을 바꾸지 않습니다.

## 1. 골목 레이더는 어떤 서비스인가요?

골목 레이더는 첫 오프라인 매장 창업을 준비하는 사람이 후보 상권을 같은 기준으로 비교해 보는 반응형 웹 서비스입니다.

사용자는 서울 25개 자치구의 공식 상권을 지도와 목록에서 탐색하고 관심 상권으로 저장한 뒤, 그중 2~4곳을 골라 점포 수, 개업·폐업률, 유동인구, 추정매출 등을 나란히 확인합니다. 화면에 표시하는 모든 숫자는 어디서 왔고 어떻게 계산했는지 확인할 수 있어야 합니다.

이 서비스는 창업 성공 여부를 예측하거나 특정 상권을 추천하지 않습니다. 공공데이터를 비교하고, 현장에서 더 확인할 질문을 정리하는 데 도움을 주는 것이 목적입니다.

## 2. 누구를 위한 서비스인가요?

- 처음 카페 창업을 준비하며 후보 상권을 비교하는 사람
- 서울에서 매장 위치를 검토하는 사람
- 숫자의 출처와 계산 근거를 직접 확인하며 판단하고 싶은 사람

## 3. 사용자가 겪는 문제는 무엇인가요?

상권 관련 숫자는 여러 공공데이터에 흩어져 있고, 데이터마다 기준 시점·공간 단위·업종 코드가 다를 수 있습니다. 단순히 숫자만 비교하면 어떤 데이터인지, 같은 시점을 비교한 것인지, 계산이 맞는지 알기 어렵습니다.

골목 레이더는 비교 기준을 하나의 분기로 맞추고, 각 지표의 원천값과 계산 근거를 함께 보여 줍니다.

## 4. 첫 MVP에서 제공할 기능

### 4.1 상권 찾기와 관심 목록

- 서울 25개 자치구의 공식 상권 1,650곳을 목록과 지도에서 보여 줍니다.
- 사용자는 목록 또는 지도에서 원하는 상권을 관심 목록에 저장하거나 해제할 수 있습니다.
- 관심 목록은 로그인 없이 현재 브라우저에 저장하며, 브라우저나 기기를 바꾸면 자동으로 동기화되지 않습니다.
- 사용자는 관심 목록에 모아 둔 상권 중 2~4곳을 비교 대상으로 선택합니다.
- 각 상권에는 이름, 자치구, 상권 코드, 상권 구분을 표시합니다.

### 4.2 최대 네 상권 비교

- 사용자는 관심 목록에서 2~4개 상권을 골라 같은 기준분기의 지표를 나란히 비교합니다.
- 초기 기준분기는 점포·매출 데이터에서 확인한 **2025년 4분기**로 합니다.
- 비교 지표는 다음과 같습니다.

| 구분 | 지표 | 표시 방식 |
| --- | --- | --- |
| 필수 | 카페 점포 수 | 원천값 |
| 필수 | 개업률·폐업률 | 원천값 |
| 필수 | 추정 유동인구 | 원천값 또는 수집·검증 후의 분기 집계값 |
| 필수 | 카페 추정매출 | 원천값 |
| 추가 | 시간대별 유동인구 분포 | 시간대 인구 ÷ 전체 인구 |
| 추가 | 주중·주말 매출 비중 | 주말 매출 ÷ 전체 매출 |
| 선택 | 건당 평균 결제액 | 매출 금액 ÷ 매출 건수 |

- 원천 데이터가 없거나 기준분기가 맞지 않는 값은 0으로 바꾸지 않고 **비교 불가**로 표시합니다.

### 4.3 숫자의 근거 보기

각 지표에서 사용자는 다음 정보를 확인할 수 있습니다.

- 제공기관과 데이터셋 이름
- 원천 파일 또는 API 수집 정보
- 기준분기와 수집일
- 상권 코드와 업종 코드
- 필터 조건
- 계산식과 반올림 규칙
- 가능한 경우 해당 결과에 사용한 원천 행

### 4.4 현장 확인 질문

- 비교한 수치만으로 알 수 없는 내용을 현장에서 확인할 질문으로 정리합니다.
- 예: 유동인구가 실제로 카페 이용 고객으로 이어지는 시간대인지, 공실과 경쟁 점포 상황은 어떤지 확인하도록 안내합니다.
- 이 기능은 통계값으로 창업 성공이나 구매전환율을 단정하지 않습니다.

## 5. 데이터와 검증 원칙

- 점포·추정매출·상권영역 데이터는 같은 상권 코드와 카페 업종 코드(`CS100010`, 커피-음료)로 결합합니다.
- 길단위인구는 Open API에서 확인한 분기 원천값을 사용하며, `20254`와 상권 코드가 일치하는 행만 표시합니다.
- 계산형 지표는 엑셀 손계산 기준표와 자동 테스트 결과가 일치해야 화면에 사용합니다.
- 데이터 출처, 파일명, 수집일, 코드 버전은 `docs/data_sources.md`에 기록합니다.

## 6. 첫 MVP에서 만들지 않는 것

- 회원가입·로그인
- 사용자 계정 기반 관심 상권 동기화와 개인 메모 저장
- 비교 리포트 공유
- 창업 추천 등급, 점수, 성공 확률, 개별 점포 매출 예측
- 매출 ÷ 유동인구를 구매전환율로 표시하는 기능
- 임의 반경으로 상권 통계를 재분배하는 기능
- 전국 상권 확대와 대출 상품 자동 연결

관심 상권은 브라우저에 저장합니다. 계정 기반 동기화, 개인 메모, 공유는 2차 프로토타입에서 검토합니다.

## 7. 화면 구성

첫 MVP는 다음 화면으로 구성합니다.

1. 상권 목록·지도와 관심 목록 화면
2. 2~4개 상권 비교 화면
3. 지표별 근거 보기 화면 또는 패널
4. 현장 확인 질문 화면

모든 주요 화면은 컴퓨터와 휴대폰 브라우저에서 사용할 수 있어야 합니다.

## 8. MVP 완료 기준

- 사용자가 지도에서 원하는 상권을 관심 목록에 저장하고 다시 방문해도 같은 브라우저에서 확인할 수 있습니다.
- 관심 목록에서 2~4개 상권을 선택해 같은 기준분기 지표를 비교할 수 있습니다.
- 모든 표시 수치에서 출처·기준분기·코드·필터·계산 근거를 확인할 수 있습니다.
- 데이터가 없거나 비교 기준이 맞지 않으면 비교 불가로 표시합니다.
- 계산형 지표는 정해진 엑셀 손계산 결과와 자동 테스트 결과가 일치합니다.
- 모바일과 PC에서 주요 비교 흐름을 사용할 수 있습니다.
